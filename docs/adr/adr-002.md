
# ADR-002: Use Local On-Device Database for Catch and Regulation Storage

Date: 2026-08-31
Status: accepted

## Context
HookIt needs to store user catch history and cross-reference those catches against a static database of fishing regulations to enforce the Domain business rules. Using a remote cloud database (like Firebase or AWS) would require live internet access to log basic catches and would force anyone reviewing the project to configure cloud environment variables.

## Decision
Use a local, on-device database accessed exclusively through the Data tier via the `CatchManager` and `RegulationData` interfaces. The Service and Domain tiers remain agnostic to the underlying storage mechanism.

## Consequences
This allows the core catch-logging and compliance features to function completely offline. It also enables reviewers and the course instructor to clone and run the application instantly without any backend setup. The tradeoff is that user data is isolated to the specific physical device and cannot natively sync across multiple devices.
