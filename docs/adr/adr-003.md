
# ADR-003: Implement Custom macOS CI Pipeline via GitHub Actions

Date: 2026-10-06
Status: accepted

## Context
The course instructor provided standard Continuous Integration (CI) templates built for Java and Python projects running on `ubuntu-latest` Linux runners. Because HookIt is a native iOS application, it strictly requires Apple's `xcodebuild` tools to compile, which are not available on Linux. 

## Decision
Discard the provided Java/Python CI templates and implement a custom GitHub Actions workflow (`ci.yml`) that utilizes the `macos-latest` runner environment to build the iOS project using command-line Xcode tools targeting an iPhone Simulator.

## Consequences
This ensures the repository strictly adheres to the course's CI automation requirement while accurately validating Swift code. It requires manually maintaining the Apple-specific build flags (e.g., disabling code signing for the headless test environment) and results in slightly longer CI build times compared to standard Linux runners.
