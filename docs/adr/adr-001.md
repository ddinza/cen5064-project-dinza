
# ADR-001: Use Native iOS (Swift/SwiftUI) instead of Cross-Platform

Date: 2026-08-24
Status: accepted

## Context
The system requires seamless integration with device hardware (camera for the AI Vision catch identification feature and GPS for the NOAA live tide data). While cross-platform frameworks (like Flutter or React Native) allow for multi-platform deployment, they add unnecessary abstraction layers and dependency management complexities for a standalone course project.

## Decision
Build the application natively using Apple's Swift programming language and the SwiftUI framework for the Presentation tier. 

## Consequences
This decision ensures high performance, native UX consistency, and immediate access to Apple's latest hardware APIs without third-party plugins. However, it restricts the application solely to the Apple ecosystem (iOS), meaning Android users cannot access the app, and it requires macOS/Xcode to compile and review the codebase.
