
# ADR 004: Integration of NOAA API for Real-Time Tide Data

**Date:** 2026-10-16
**Status:** Accepted

## Context
The application originally relied solely on the Gemini Vision API for core functionality. However, user safety and fishing success are heavily dependent on tide conditions. We needed a reliable, authoritative source to provide local tide schedules without requiring a heavy offline data payload.

## Decision
We integrated the NOAA (National Oceanic and Atmospheric Administration) CO-OPS API to fetch real-time tide data based on the user's GPS coordinates. 

## Consequences
**Positive:** 
* Provides highly accurate, government-backed marine data.
* Enhances the core domain value of the application for anglers.

**Negative/Mitigation (Fallback Strategy):**
* Introduces a second external network dependency. 
* **Fallback Behavior:** If the NOAA API is unavailable, times out, or the user lacks a network connection, the application degrades gracefully. The networking service catches the failure, hides the dynamic tide widget on the UI, and displays a localized alert: *"Live tide data currently unavailable. Please consult local charts."* This ensures the core app (and local AI features) remain functional without crashing.
